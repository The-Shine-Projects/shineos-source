# ShineOS Source

Source files of ShineOS, a Debian-based GNOME distribution by The Shine Project.

- `icons/`: Starcons icon theme
- `plymouth/`: boot splash theme
- `settings/`: default desktop settings
- `tools/`: helper scripts

ISO build recipe: https://github.com/The-Shine-Projects/shineos-live-build
See SOURCES.md for where to find the rest of the source.
