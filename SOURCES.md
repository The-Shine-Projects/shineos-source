# Where to get the source of ShineOS

ShineOS is a Debian-based GNOME distribution by The Shine Project.

- ISO build recipe: https://github.com/The-Shine-Projects/shineos-live-build
- ShineOS own components: https://github.com/The-Shine-Projects/shineos-source
- Debian packages (unmodified): https://sources.debian.org and https://snapshot.debian.org
- Linux kernel: shipped as the unmodified Debian kernel package
- GNOME Shell extensions: source with their own LICENSE files in the build recipe repository

The exact package list of each release is attached to the release as shineos-amd64.packages.
